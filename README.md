# DATJ — Gold & Silver Atelier

High-jewelry atelier e-commerce platform for authentic 22KT / 18KT gold, IGI-certified natural diamonds, and solid 925 sterling silver.

## Features
- **Strict Quiet Luxury Theme**: Deep Imperial Emerald (`#062319`) and Sterling Silver Frost (`#8ebfa8`, `#eaf1ed`) palette.
- **Multi-Angle Jewelry Studio Views**: Interactive angle selectors (`Studio Front`, `Setting & Macro`, `Side Profile`, `Hallmark & Box`) for each piece.
- **Transparent Precious Metal Calculator**: Real bullion rate pricing (weight × rate + making charges + 3% GST).
- **Sticky Parallel Stacking Cards**: Scroll-driven "The Datj Standard" feature showcase.
- **Live Bullion Ticker**: Daily MCX benchmark rates for 24K, 22K, 18K gold and 925 silver.
- **Government Authentication**: BIS 916 & 925 hallmark verification with 6-digit laser HUID display.
- **Responsive Navigation**: Desktop mega-menu and touch-optimized mobile drawer.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM v7

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
